**Status**: Approved (user sign-off via AskUserQuestion 2026-05-26)

## Context

User has three project-local research workflows that have been validated across multiple investment-research projects:

- `light-research` (already published in `market-research-skills` plugin) — 60-80 min, 5-page memo, no charts
- `medium-research-archived` (project-local) — half-day, 10-page brief, 3-8 charts
- `heavy-research-archived` (project-local) — multi-week, 15k+ words, 30+ charts, multi-LLM

User wants to package medium + heavy into a single distributable skill with mode selection at trigger time. The skill becomes part of a personal AI/finance portfolio targeted at MENA job market.

## Decisions (locked via user sign-off)

1. **Single skill, three modes.** Skill name `analyst-research`. Internal modes: `light` / `medium` / `heavy`. Modes selected via AI-driven prompt at trigger time.
2. **Mode-picker UX.** When user triggers the skill without specifying a mode, AI presents three options with runtime estimates and lets user pick. No flag-based dispatch in V1.
3. **Repo structure.** New standalone repo `analyst-research/` (sibling to existing `market-research-skills/`), multi-skill plugin format mirroring user's existing pattern. Single skill in V1, room for future expansion.
4. **Plugin packaging.** `.claude-plugin/marketplace.json` + `plugin.json` so users install via `/plugin marketplace add` + `/plugin install`.
5. **License.** MIT (matches existing `medium-research-archived/LICENSE`; commercial-friendly for portfolio context).
6. **Language.** Skill content bilingual where it already exists (workflow.md and spec stay Chinese, SKILL.md adds EN). README EN-primary with Chinese section.
7. **Portfolio site.** Astro + Tailwind + GitHub Pages, EN V1, Chinese toggle deferred to V2.

## Mode comparison

| Dimension | light | medium | heavy |
|---|---|---|---|
| Output length | ≤5 pages | 10-15 pages | 15k+ words |
| Charts | 0 | 3-8 | 20-35+ |
| Runtime budget | 60-80 min | 3-5 hours | days-weeks |
| LLM model | single | single | single or multi-LLM |
| Workflow steps | 6 | 8 | 11 |
| Derived outputs | PDF + Word | PDF + Word | PDF + Word + WeChat md + HTML publication |
| Citation style | Markdown footnote | Markdown footnote | BibTeX + APA |
| User checkpoints | 0 hard stops | 1 (sign-off) | 3 (outline, draft, sign-off) |

## Mode dispatcher (SKILL.md behavior)

When triggered without an explicit mode hint in user message:

```
AI: Starting analyst-research. Please pick a scope:

  --light    5-page decision memo, 0 charts, 60-80 min budget
             Use for: exec brief, quick decision support, 1-hour briefing

  --medium   10-15 page topic analysis, 3-8 charts, half-day budget
             Use for: topic deep-dive, board memo with data, half-day analysis

  --heavy    Long-form report 15k+ words, 20-35+ charts, days-weeks budget
             Use for: industry report, macro thesis, policy assessment,
             flagship publication
```

When user message contains explicit hints (page count, time budget, chart count), AI infers mode and asks one-line confirmation.
